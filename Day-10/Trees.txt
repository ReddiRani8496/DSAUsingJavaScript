A tree is a non-linear, hierarchical data structure consisting of nodes connected by edges. Unlike linear structures (arrays, linked lists), it represents hierarchical relationships.

Root: The topmost node of the tree (the only node with no parent).

Edge: The link connecting a parent node to a child node.

Leaf Node (External Node): A node that has no children.

Internal Node: A node with at least one child.

Depth of a Node: The number of edges from the root to that specific node.

Height of a Node: The number of edges on the longest path from that node to a leaf.

Height of a Tree: The height of the root node (the longest path from root to any leaf).

Subtree: Any node along with all its descendants.


Properties of Trees
N nodes = N - 1 edges. Every node except the root has exactly one incoming edge from its parent.

No Cycles: There are no loops or closed paths. A tree with a cycle is just a graph.

Unique Path: There is exactly one unique path between the root and any other node.

Common Types of TreesA. 
Binary Tree: A tree where each node can have at most two children, typically referred to as the left child and right child.Full Binary Tree: Every node has either 0 or 2 children.
Complete Binary Tree: All levels are completely filled except possibly the last level, which is filled from left to right.
Perfect Binary Tree: All internal nodes have two children, and all leaf nodes are at the same level.B. 
Binary Search Tree (BST)A binary tree with a strict ordering property:The value of the left subtree must be less than the parent node's value.The value of the right subtree must be greater than the parent node's value.Both left and right subtrees must also be binary search trees.
Time Complexity (BST):Average Case: $O(\log n)$ for Search, Insertion, and Deletion.Worst Case: $O(n)$ if the tree becomes skewed (looks like a linked list).
